EIS 75TH ANNIVERSARY INTERACTIVE GAMES
=======================================

SETUP INSTRUCTIONS
------------------
1. Double-click "EIS-75th-Games.exe" to launch
2. Games will open full-screen on the primary display
3. No internet connection required
4. No installation required

EXITING THE APPLICATION
-----------------------
- Press ESC once to exit full-screen (windowed mode)
- Press ESC again to quit the application

GAMES INCLUDED (6)
------------------
1. Disease Detective — Solve historical outbreak mysteries
2. Outbreak Network — Contact tracing puzzle
3. First Response — PPE and investigation sequencing
4. Outbreak Command — Epidemic response decisions
5. Predict the Outbreak — Epi curve forecasting
6. 75 Years, 75 Stories — Video archive

TROUBLESHOOTING
---------------
- If the screen is black, wait 5-10 seconds for loading
- If touch is unresponsive, try pressing ESC and restarting
- The app auto-resets to the home screen after 90 seconds of inactivity
- The home screen shows an attract animation after 45 seconds of inactivity

TECHNICAL NOTES
---------------
- Target resolution: 1920x1080 landscape
- All content is bundled — no internet required
- Game progress resets when the app is restarted
